Active Directory sits at the center of an organization’s identity infrastructure. If it is compromised, attackers can gain control over users, permissions, and access to critical systems. Restoring it is both urgent and notoriously difficult.

Semperis had already solved a significant part of that problem. Its mature backup product could back up and restore Active Directory with a single action—a level of automation and reliability that competitors had not reached.

The next step was a natural one: don’t wait for Active Directory to be compromised. Detect the vulnerabilities and dangerous configurations that make an attack possible, then alert the security team while there is still time to act.

That idea marked the beginning of Semperis’s security product. The system needed to continuously examine Active Directory, identify weaknesses, and translate them into alerts, insights, and notifications that security teams could understand and prioritize.

There was already an interface for backup and recovery, but it had been built quickly, before an internal design function existed. It supported the operation, but it wasn’t a foundation for an expanding security platform. Backup and restore is a defined task; security monitoring is continuous. It introduces severity, urgency, changing states, large volumes of findings, and very different decisions.

My role was to develop the UX and visual language for that transition. We had to define what constituted an alert, how it differed from an insight or notification, how risk should be communicated, and how users could move from detecting a weakness to understanding what required attention.

The work wasn’t simply a redesign of the existing interface. It was the creation of a product language that allowed Semperis to grow from an exceptional recovery tool into an Active Directory security platform—helping organizations recover when something went wrong, while increasingly preventing them from reaching that point at all.
