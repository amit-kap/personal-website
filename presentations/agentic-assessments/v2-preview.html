* Quick assessment: when an assessment starts, the agent gathers all available public data, so the user can make an initial decision without waiting on the back-and-forth with the vendor.

When an assessment starts, the agent runs a Quick assessment on all available public data. Inside the loop the agent recommends which questionnaire to send, analyzes vendor replies, recommends a follow-up or a decision, and handles all the back-and-forth with the vendor, alerting the person only when needed. The person can make an initial decision right away instead of stalling on the vendor back-and-forth, and can re-assess with the vendor at any time.

Technical approach and cost

Agent pipeline

Evidence intake, mapping to controls, drafting follow-ups, parsing replies into proposed verdicts.

Security of the feature

Vendor data handling, tenant isolation, and outbound email sent on the customer’s behalf.

Evaluation as a product surface

Track where the agent is right, where it fails, and where people override it. Show it to customers.

Cost

Model cost per assessment and margin impact: $5–15 per assessment (est.), under 2% of the add-on price. Confirmed in Phase 1.

The hard part is evaluation and safe outbound communication. Phase 1 keeps the agent’s output behind human approval.

Earn trust in three phases

Phase 1 · ask todayFollow-up wedge

Agent drafts vendor follow-ups; a person approves; replies become proposed verdicts. 8 people, one quarter (est.).

Gate

≥ 80% drafts approved unedited, overrides ≤ 10%, after 90 days with design partners.

Phase 2Fleet and channel

The agent runs whole assessments; people review exceptions in the fleet view and channels.

Gate

Analyst hours −50%, zero critical findings missed in audit samples.

Phase 3Policy and autonomy

Plain-language policy; autonomy expands only where measured results support it.

Gate

Per-customer override and accuracy data.

We are only asking for Phase 1 today. Each later phase needs its gate met and comes back to this group.
